那如何先画一条垂直或者水平线？

最简单就是用 LINE + 正交 F8。

操作：

输入 L，回车。
点一下起点。
按 F8，打开“正交模式”。
移动鼠标：
往左/右移动，就是严格水平线。
往上/下移动，就是严格垂直线。
输入长度，比如 100，回车。

比如：

画一条长度 100 的水平线：L → 点起点 → F8 → 鼠标向右 → 输入 100 → 回车。
画一条长度 100 的竖直线：L → 点起点 → F8 → 鼠标向上 → 输入 100 → 回车。

你也可以完全不用鼠标方向，直接输入相对坐标：

向右 100：@100,0
向左 100：@-100,0
向上 100：@0,100
向下 100：@0,-100
结合你这几次作业里实际用到的 AutoCAD 操作，常见快捷命令可以先记这一批。课件里也主要围绕绘图、修改、对象捕捉、图层和文字这些功能展开。

* `L`：LINE，直线
* `PL`：PLINE，多段线
* `C`：CIRCLE，圆
* `A`：ARC，圆弧
* `REC`：RECTANG，矩形
* `POL`：POLYGON，多边形
* `O`：OFFSET，偏移
* `TR`：TRIM，修剪
* `EX`：EXTEND，延伸
* `M`：MOVE，移动
* `CO`：COPY，复制
* `RO`：ROTATE，旋转
* `SC`：SCALE，缩放
* `MI`：MIRROR，镜像
* `F`：FILLET，圆角
* `CHA`：CHAMFER，倒角
* `BR`：BREAK，打断
* `E`：ERASE，删除
* `X`：EXPLODE，分解

图层和属性方面最常用的是：

* `LA`：打开图层特性管理器
* `MA`：MATCHPROP，特性匹配
* `PR` 或 `Ctrl+1`：打开“特性”面板
* `QSELECT`：快速选择
* `CH`：也可打开特性

文字与标注：

* `T` / `MT`：多行文字
* `DT`：单行文字
* `STYLE`：文字样式
* `D`：标注样式管理器
* `DIM`：智能标注
* `DLI`：线性标注
* `DAL`：对齐标注
* `DRA`：半径标注
* `DDI`：直径标注

视图和辅助：

* `Z`：ZOOM，缩放视图
* `P`：PAN，平移视图
* `RE`：REGEN，重生成
* `F3`：对象捕捉开/关
* `F8`：正交开/关
* `F10`：极轴追踪开/关
* `F11`：对象捕捉追踪开/关
* `Ctrl+Z`：撤销
* `Ctrl+Y`：重做

文件与输出：

* `SAVE`：保存
* `SAVEAS`：另存为
* `OPEN`：打开
* `NEW`：新建
* `PLOT`：打印
* `LIMITS`：设置图形界限
* `UNITS`：设置单位

你这次作业尤其高频的是：

`L → O → C → POL → TR → M → LA → STYLE → QSELECT → Ctrl+1`
