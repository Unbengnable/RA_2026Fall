# RRRP 第六题：最小运行包

## 文件

- `RRRP_Q6_Tuned.slx`：已调参的 RRRP Simulink 模型。
- `init_RRRP.m`：模型使用的连杆、目标轨迹、PID 基准参数和仿真时间。**必须先运行。**

本文件仅说明操作，不是模型的运行依赖。需要 MATLAB R2026a、Simulink、Simscape 和 Simscape Multibody。

## 手动启动

把本文件夹解压到任意位置，在 MATLAB 的“当前文件夹”切换到解压后的文件夹，然后逐行输入：

```matlab
run('init_RRRP.m')
open_system('RRRP_Q6_Tuned.slx')
out = sim('RRRP_Q6_Tuned','StopTime','60');
```

也可以运行初始化后，打开模型并点击 Simulink 的“运行”。每次新开 MATLAB 或清空工作区后，都需要重新运行初始化脚本。模型中的 Scope 可查看关节响应。`init_RRRP.m` 会执行 `clear`，请在仿真之前运行它。

## 调参方法与结果

课件原值为 R1 `(Kp,Ki,Kd)=(30,1,8)`、R2 `(25,1,6)`、R3 `(20,0.5,5)`、P4 `(60,0,20)`。我先把各关节的三个增益分别降到 25%，用相同的错峰五次多项式轨迹和 8 s 时间窗比较目标与实际轨迹。然后每次只降低一个关节，定位主要误差来自哪一个控制通道。四关节同时降低增益时，R1、R2、R3 的跟踪 RMSE 从原来的 `1.4335°、0.9584°、0.8821°` 增至 `5.8046°、3.3098°、1.7496°`；P4 的变化很小。

随后固定 P4 与三个转动关节的积分增益，只在课件原值附近测试九组比例、微分倍率，用三个转动关节的 RMSE 之和选择一组。该模型采用：

| 关节 | Kp | Ki | Kd |
|---|---:|---:|---:|
| R1 | 60 | 1 | 20 |
| R2 | 50 | 1 | 15 |
| R3 | 40 | 0.5 | 12.5 |
| P4 | 60 | 0 | 20 |

前三关节的 Kp 为原值 2 倍，Kd 为原值 2.5 倍。三个转动关节的 RMSE 之和从 `3.274°` 降至 `1.959°`。60 s 复测时，10 s 后三个转动关节的最大绝对误差分别为 `0.00216°、0.00689°、0.0120°`。这些数据仅针对课件给定轨迹和模型；九组有限搜索不代表全局最优。

手动继续调参时，先只改变一个关节：响应滞后且无明显振荡时逐步增加 Kp；超调或摆动明显时增加 Kd 或降低 Kp；稳定后仍有持续偏差时再小幅增加 Ki。P4 已有重力补偿且 Ki=0，因此本次保持其参数不变。增益进一步变大前，应检查驱动力矩或力、执行器限幅和微分对噪声的放大。
